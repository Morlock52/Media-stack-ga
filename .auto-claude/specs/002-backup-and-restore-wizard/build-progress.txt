- **Loading States:** Shows spinner during initial discovery and refresh operations

  - Configuration Files (FileCode icon)
  - Databases (Database icon)
  - Metadata (Clapperboard icon)
  - Docker Volumes (HardDrive icon)
- **Size Display:** formatBytes() utility converts bytes to human-readable format (B, KB, MB, GB, TB)
- **Selection UI:**
  - Individual checkboxes for each item with service badges
  - Type header checkboxes to select/deselect all items of that type
  - Select All / Deselect All buttons for quick actions
  - Visual feedback with checkmarks and color coding
- **Summary Bar:** Shows "X / Y items" and "size / total" at top
- **Empty States:** Helpful message when no containers are running
- **Warning States:** Alert when no items selected
- **Refresh Button:** Manual re-scan of running containers
- **Responsive Design:** Grid layout adapts to screen size

**Implementation Details:**
- Uses useBackupStore for state management (availableItems, selectedItems, toggleItem, selectAllItems, deselectAllItems)
- Uses useBackupDiscover hook to fetch targets from GET /api/backup/discover
- Follows existing patterns: InteractiveCard, motion animations, toast notifications, Button variants
- Type-safe with BackupItem and BackupItemType interfaces from store
- Helper functions: formatBytes(), groupItemsByType(), getTypeIcon(), getTypeName(), isItemSelected(), isTypeFullySelected(), toggleTypeGroup()
- Clean checkbox styling matching existing SettingsPage patterns
- Proper truncation for long paths and service names
- Loading state on initial mount and manual refresh
